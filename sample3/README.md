# MCTS visualization sample 3

(from <a href="https://imgur.com/a/where-is-actual-blind-spot-H4D6t7k">"Where is the actual blind spot?"</a>)

Using an old 20b model for reproduction.

* [Truncated diagram](https://kaorahi.github.io/visual_MCTS/sample3/stone_tower_squeeze.html)
* [Full diagram](https://kaorahi.github.io/visual_MCTS/sample3/stone_tower_squeeze_full.html)

Along the principal variation (the red edges), White 8 (D5) is the first key move. Its initial evaluation (indicated by the border color) is poor for White, even though it is actually the winning move. Further down, red nodes appear; hovering over them and examining the board reveals that the sequence is the classic Stone Tower Squeeze.
